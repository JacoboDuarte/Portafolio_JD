# Portafolio personal

Sitio web personal de Jacobo Duarte, desarrollado con HTML, CSS y Bootstrap.

## Páginas

- `index.html`: perfil, habilidades, proyectos e intereses.
- `contacto.html`: formulario de contacto y mapa.

## Publicación en GitHub Pages

En GitHub, abre **Settings > Pages**, selecciona la rama `main` y la carpeta `/ (root)`, y guarda los cambios. La página principal del sitio es `index.html`.
